FAQ

Clear answers before you try it.

Everything OrcaFind generates is a draft. You keep control, edit the output, and publish when it’s ready.

What gets generated?

One run returns posts and captions together, so you can ship distribution faster.

  • X post variations or an X thread style (selected in the Studio)
  • LinkedIn post draft with clean structure
  • Instagram caption
  • Facebook caption
Do I need a perfect prompt?

No. Start with a strong source draft. Add a quick audience and takeaway if you want tighter pacing.

Is AI image generation free?

No. Image generation is Pro-only. Pro users can generate up to 3 image options per run.

What if I only want captions?

You can still run the workflow and only use the captions you need. Everything arrives in one results stream.

Where do I manage my account?

Use the Profile page to view your plan and usage, and to sign out.
